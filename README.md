# Будова слова: потяг-детектив

Інтерактивна гра для початкової школи, у якій учні розбирають слова за будовою: знаходять закінчення, основу, корінь, префікс і суфікс. Тема й порядок розбору відповідають навчальному плакату з потягом: закінчення → основа → корінь → префікс → суфікс.

## Посилання

https://lvnotes.github.io/word_structure/

## Як це працює

Гра складається з 4 рівнів, по 6 завдань у кожному (усього 24). Слова добираються випадково із запасу, тому під час повторного проходження завдання щоразу трохи інші.

| Рівень | Що потрібно зробити |
|---|---|
| 1. Закінчення | Позначити букви, які змінюються при зміні форми слова (книга — книги). Якщо закінчення немає, натиснути «Нульове закінчення». |
| 2. Корінь | Знайти спільну частину споріднених слів, а також знайти зайве слово, яке не є спорідненим. |
| 3. Префікс і суфікс | Позначити в слові префікс і суфікс. |
| 4. Повний розбір | Позначити всі частини слова: префікс, корінь, суфікс і закінчення, не забувши про нульове закінчення. |

У завданнях на розбір слово складається з літерних «кубиків». Учень обирає потрібну частину (колір відповідає частині слова) і торкається букв, які до неї належать.

## Перевірка та підсумок

- Правильні відповіді підсвічуються **зеленим**, помилки — **червоним**.
- Після помилки показується правильний розбір слова з підписами частин.
- Кнопка «Підказка» відкриває пам'ятку з порядком розбору слова.
- У кінці гри з'являється підсумок: загальний бал із 24, зірочки, результат за кожним рівнем та список слів, над якими варто ще попрацювати.

## Для кого

Для учнів початкових класів (орієнтовно 3–4 клас) як закріплення теми «Будова слова» на уроці, в групі подовженого дня або вдома. Працює у браузері на комп'ютері, планшеті та телефоні, не потребує встановлення.
